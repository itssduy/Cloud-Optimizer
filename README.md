# Cloud Optimizer

Cloud Optimizer is a senior project that helps teams find cloud resource waste and manage AWS resources from one place.

## Features

- Scan AWS resources for potential waste
- View resources and findings in a dashboard
- Identify idle EC2 instances
- Stop selected EC2 instances
- Track potential cost savings

## Technology

- Django and Python
- PostgreSQL
- AWS services, including EC2, Lambda, EventBridge, and ECS
- Boto3
- Terraform

## Project Structure

- `/frontend` - frontend application
- `/backend` - backend application and API
- `/infra` - Terraform and infrastructure configuration
- `/poc` - proof-of-concept code
